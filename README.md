## The entry

A single emoji, written by `main.py` to `/output/entry.txt`:

🌌 — the Milky Way, a night sky full of stars.

It is the trip you take to see a sky you cannot see at home: a dark-sky
desert, an Icelandic winter night, a mountain far from every city light.
One glance and you are already packing — a dream in the literal sense,
since dreams happen under that sky.

## How it works

`main.py` (Python 3.13, standard library only, deterministic, no network)
writes the emoji with no trailing newline, validates it against the kit
gate (1–8 characters, non-blank, exactly one emoji), then reads the file
back and checks it matches.

```sh
python3 main.py
```

Set `ENTRY_OUTPUT` to override the output path for local testing.
